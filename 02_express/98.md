## 98. Advance logging with morgan and winston



Summary:
Overview:
This walkthrough focuses on enhancing the backend application by adding custom logging functionality using popular logging libraries, such as Winston and Morgan, to monitor and debug Express.js applications effectively. Logging is essential for debugging, measuring performance, and optimizing backend systems.

Existing Setup Recap:
An Express.js application has been built with routes to handle:
POST requests to add a new tea (/teas).
GET requests to retrieve all teas or a specific tea.
PUT and DELETE routes for updates and deletions.
The app is tested using Postman, sending raw requests (e.g., name and price) to the defined routes.
Current logging is minimal, only outputting simple console logs (e.g., "POST route hit").
Challenges with Basic Logging:
Lack of detailed information:
No data on which endpoints are being hit, request payloads, or response details.
No timestamps or response times to analyze performance.
Inefficient debugging for complex applications:
Difficult to optimize APIs without measuring key metrics.
No persistence of logs for later analysis.
Solution: Adding Advanced Logging with Winston and Morgan:
Popular Logging Libraries:

Winston: Flexible and configurable for advanced logging.
Morgan: Lightweight HTTP request logger middleware.

Setting Up a Logger File:

Create a new file (e.g., logger.js) to configure the logging behavior.
This file will define custom logging formats and transports (e.g., console or file-based logging).
Configuration Overview:

Import Winston and configure it:
javascript
Copy
Edit
const { createLogger, format, transports } = require('winston');
const { combine, timestamp, printf } = format;
Logger Format:
Customize how log messages appear using combine, timestamp, and printf.
Example:
javascript
Copy
Edit
const logFormat = printf(({ level, message, timestamp }) => {
  return `${timestamp} [${level.toUpperCase()}]: ${message}`;
});
Logger Transports:
Define where logs are sent:
Console: Display logs in the terminal.
File: Save logs to a file for persistent storage.
Example:
javascript
Copy
Edit
const logger = createLogger({
  format: combine(timestamp(), logFormat),
  transports: [
    new transports.Console(),
    new transports.File({ filename: 'application.log' })
  ],
});
Integrating Morgan with Winston:

Combine Morgan and Winston for HTTP request logging.
Example:
javascript
Copy
Edit
const morgan = require('morgan');
const logger = require('./logger'); // Winston logger

app.use(
  morgan('combined', {
    stream: {
      write: (message) => logger.info(message.trim()),
    },
  })
);
